# NEXUS AI Website – Version 1.0

Eine responsive, zweisprachige (Deutsch/Englisch) Premium-Landingpage für NEXUS AI.
Reines HTML, CSS und JavaScript – keine Build-Tools und keine Frameworks erforderlich.

## Lokal testen
1. ZIP entpacken.
2. `index.html` im Browser öffnen.
3. Oben rechts mit `EN` / `DE` die Sprache wechseln.

## Vor der Veröffentlichung unbedingt erledigen
1. In `script.js` `DOWNLOAD_URL` durch die echte GitHub-Release-URL ersetzen.
2. `SUPPORT_EMAIL` in `index.html` durch eine echte Support-Adresse ersetzen.
3. Impressum und Datenschutzerklärung erstellen und verlinken. Die aktuelle Seite enthält dafür nur einen sichtbaren Hinweis, keine fertigen Rechtstexte.
4. Produkt-Screenshot in der Hero-Sektion durch einen echten Screenshot der Anwendung ersetzen, sobald verfügbar.
5. Prüfen, dass alle Aussagen zu Funktionen, Betriebssystemen und KI-Anbietern exakt zur veröffentlichten Anwendung passen.
6. Die Seite auf Smartphone und Desktop testen.

## Hosting-Empfehlung
Für die erste statische Website empfehle ich Cloudflare Pages oder GitHub Pages. Die Website kann öffentlich sein, ohne dass das private Quellcode-Repository der NEXUS-AI-Desktop-Anwendung veröffentlicht werden muss. Das Website-Projekt selbst enthält keinen App-Quellcode.

## Hinweise
- Der Download-Button ist absichtlich noch nicht mit einer erfundenen URL verbunden.
- Google Fonts werden extern geladen; für eine datenschutzfreundlichere Veröffentlichung können die Schriftdateien lokal eingebunden werden.
- Noch keine Zahlungsfunktion, kein Nutzerkonto und kein Tracking.
